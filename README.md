# Kuai translate

[English](docs/README.en.md) · [开发说明](docs/development.md) · [参与贡献](CONTRIBUTING.md) · [隐私说明](PRIVACY.md) · [UI/UX 整理](docs/ui-ux-review.md)

Kuai translate 是一个独立实现的浏览器翻译扩展，提供网页双语翻译、划词翻译、自配 API，以及 YouTube 双语字幕和侧边字幕列表。默认可选择微软、谷歌、腾讯 Transmart 和 Yandex 的免 Key 网页翻译接口，也可以只使用你自己的 API 服务。

项目采用 **TypeScript、原生 ESM、HTML、CSS 和 Manifest V3**。开发与打包使用 **Node.js 24 及以上版本、pnpm 和 TypeScript**；Chrome/Node 类型仅用于开发，浏览器运行时无第三方依赖，不需要框架、bundler 或项目服务器。没有登录、会员、推广、遥测或卸载跳转页面。

这是新的源码项目，具有独立的扩展身份；它不包含此前成品扩展的编译包，也不声称恢复了旧产品的全部源码和功能。来源与许可边界见 [实现来源](docs/provenance.md)。

## 功能范围

| 功能 | 当前行为 |
| --- | --- |
| 网页双语 / 仅译文 | 默认原文与译文对照，译文保留对应的可点击链接；仅译文模式只在该段翻译成功后隐藏原文，失败时保留原文 |
| 网页译文样式 | 16 种预设及字体、颜色、透明度和行高；可从扩展弹窗或设置页进入，修改样式不重复翻译 |
| 网页触发与范围 | 手动翻译，或启用按网站/原文语言自动翻译；可继续处理动态正文，配置排除区域与快捷键 |
| 划词翻译 | 取消选区自动关闭结果；图钉图标可固定并移动弹窗，继续划词复用位置；保留独立服务、语言与触发配置 |
| 输入翻译 | 默认英文，输入区内的小圆点或 Alt+X 触发；直接写回，不自动打开结果卡；可取消、重试、恢复或复制无法写入的译文 |
| 段落快捷翻译 | 与整页翻译共用译文；指向段落后按一次 Shift 翻译，再按一次关闭，键盘松开后仍继续完成请求 |
| YouTube 字幕与设置 | 独立字幕服务和目标语言，双语 / 仅译文、显示顺序及字体颜色位置；设置入口不依赖字幕下载成功 |
| YouTube 侧边字幕列表 | 独立的紧凑阅读样式，原文在上、译文在下；时间戳跳转、当前句标记，手动滚动后可回到当前字幕 |
| 字幕学习遮罩 | 模糊已有译文，悬停或键盘聚焦后显示；与字幕显示模式独立 |
| 字幕文本选择 | 选中字幕文字时固定当前字幕并暂停播放；取消选中时，只恢复由本扩展因本次选择而暂停的播放 |
| 自配翻译服务 | 支持多个独立实例、接口获取模型列表并选择（也可手填）、测试连接及本地保存 |
| 文本和文件翻译 | 独立页面支持粘贴文本以及 TXT、MD、SRT、VTT 文件，保留原文，显示并下载译文 |
| 配置备份 | 默认导出不含 API Key；可选择包含密钥，并导入可识别的旧版直连/免费配置、样式和交互选项 |

**本版不包含 OCR、PDF 版式翻译、电子书、会议转写或其他视频站点集成。** 也不提供多模型评分选优、手机手势或上下文摘要翻译。PDF 浏览器页面不是本版的文档翻译入口。

网页翻译默认由你触发，处理当前已载入的可读正文；可另外开启自动翻译和动态内容翻译。默认保留双语对照，选择仅译文时仍保留原始节点以便恢复。浏览器内部页、扩展商店等受保护页面不允许注入本功能；这些限制不能通过增加快捷键或网站规则解除。

AI 服务配置：填写 API 地址（留空使用默认地址）与自己的 Key 后，点击“获取模型”，从列表选择即可自动保存，无需手填模型名。支持 OpenAI 兼容、Gemini、Anthropic Claude 和 Ollama；获取失败或列表为空时仍可手填。Ollama 列出服务端已安装模型，自建服务可不填 Key。

## 安装

目标环境为支持 Manifest V3 的 Chromium 浏览器，例如 Chrome 或 Edge。当前版本未提供 Firefox 专用清单或兼容性承诺。

### 从源码构建

1. 将源码下载、解压或克隆到本地，进入含有 `package.json` 的目录。
2. 确认已经安装 Node.js 24 或更高版本。
3. 执行：

```bash
node --version
pnpm test
pnpm build
pnpm check
```

首次开发先运行 `pnpm install --frozen-lockfile` 安装编译器和 API 类型。`pnpm verify` 执行严格类型检查、构建、回归测试和产物检查；浏览器加载 `dist/`。

4. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
5. 选择“加载已解压的扩展程序”，选中生成的 **`dist/` 目录**。
6. 刷新已经打开的网页，再点击 Kuai translate 的扩展图标。

修改源码后，重新执行 `pnpm build`，在扩展管理页点击重新加载，再刷新目标网页。不要直接修改生成的 `dist/`：下次构建会覆盖它。

### 使用已打包的扩展 ZIP

如果维护者提供了 `kuai-translate-1.0.0.zip`：

1. 将 ZIP 解压到一个准备长期保留的目录。
2. 在扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。
3. 选中**直接包含 `manifest.json` 的目录**。

安装扩展 ZIP 不需要 Node.js。名称带 `-source.zip` 的文件是源码包，需要先按上面的步骤构建。ZIP 不是商店安装包，不能把它当作 CRX 双击安装。

### 更新已安装的 Kuai translate

要保留现有未打包扩展的本地 ID 和设置，请使用**原来加载的目录和原来的扩展条目**：

1. 可先在设置页导出配置备份。
2. 将新版安装 ZIP 的内容覆盖到原先解压、加载的目录；从源码运行时，则在同一个项目路径重新构建同一个 `dist/`。
3. 在 `chrome://extensions` 或 `edge://extensions` 找到已有的 Kuai translate，点击“重新加载”，然后刷新正在使用的网页和 YouTube 页面。

更新时不要先卸载现有扩展，也不要每次换一个版本号目录重新“加载已解压的扩展程序”。另一个目录可能产生新的扩展 ID，其本地配置不会自动继承；需要在新实例的设置页手动导入备份。默认不含 Key 的备份不能为全新实例恢复密钥，需重新填写，或由你明确选择导出包含密钥的私人备份。

## 网页、划词与输入配置

设置页提供网页、划词、输入、YouTube 字幕和翻译服务分区；段落快捷翻译放在网页翻译内。网页默认使用微软服务，原文语言自动检测、目标为简体中文。划词与输入的**服务、原文语言和目标语言可以逐项独立选择**；划词初始跟随网页，输入的服务和原文语言跟随网页、输出默认英文。段落快捷翻译与整页共用服务、语言、显示模式和样式。字幕的独立服务与目标语言设置保持不变。

### 默认操作与可选触发

| 区域 | 初始行为 | 可调整内容 |
| --- | --- | --- |
| 网页 | **Alt+Z** 翻译 / 恢复原文；自动翻译与动态翻译关闭；按当前可见区域翻译，滚动后补译，范围可包含页脚；最少 1 字符；右键菜单开启 | 网站、原文语言、CSS 排除规则；最少 1–200 字符；翻译快捷键和显示模式快捷键 |
| 划词 | 默认关闭；开启后选中等待 **250 ms** 自动翻译；最多 **5000** 字符；卡片显示原文；自动朗读关闭 | 自动、图标、圆点、Shift / Alt / Control / Meta；图标或圆点可点击或悬停激活，默认点击；等待 0–2000 ms，上限 1.0.000 字符 |
| 输入 | 开启，**Alt+X** 翻译，再按一次恢复最近一次替换；直接写回，不弹结果卡；输出英文；显示简洁圆点，点击展开翻译图标，再点击图标翻译；写回不附带原文 | 圆点、图标或隐藏入口；先预览再应用、同时保留原文、原文/译文顺序及快捷键；右键“本站禁用输入翻译”；顺序默认原文在前 |
| 段落 | **开启**；可在弹窗关闭。指向段落后按一次 **Shift** 翻译，再按一次关闭；提示框开启 | Control / Shift / Alt 或 1–2 个自定义组合键；段落/区域；可选自动悬停或长按左键，只有鼠标触发方式使用等待时长 |

划词的修饰键模式支持先选中、再按键；图标/圆点只有被激活才发出请求，点击立即触发，悬停按所设延迟触发。自动朗读只用于单个原文单词，使用浏览器可用的**本机语音**；没有合适语音就跳过，不切换到远程语音服务。

网页和输入的动作快捷键格式为“一个或多个修饰键 + 一个 A–Z 字母”，例如 `Control+Shift+K`；可写 `Ctrl`、`Cmd` / `Command`、`Opt` / `Option`，留空即关闭。网页的显示模式快捷键默认留空；配置后，已有译文时切换双语/仅译文，尚无译文时会启动翻译。网页快捷键在非编辑区域生效；输入快捷键只在可处理的编辑区域生效。组合输入、长按产生的重复键事件不会反复触发，系统或浏览器占用的组合可能无法使用。

段落的“自定义快捷键”允许 **1–2 个不同按键组合**，可选 Control、Alt、Shift、Meta / Cmd 和 A–Z，例如 `K`、`Control+K` 或 `A+B`。组合按下并松开一次切换当前段落；不会因为一直按住或移动鼠标而连续翻译。完整动作组合不会顺带触发段落操作；自定义为 Alt 时，Alt+Z、Alt+X 也不会误触单独 Alt。输入区、组合输入和文字选区仍有各自的操作优先级。

### 段落与整页共用同一套译文

在扩展弹窗启用“段落快捷翻译”，或在“设置 → 网页翻译 → 段落快捷翻译”调整按键。

1. 鼠标指向段落，按一次 **Shift**，在该段显示译文；按键松开后请求继续执行，不必等着译文出现。
2. 再按一次 **Shift**，关闭这一段译文。还在翻译时也可关闭，迟到结果不会重新出现。
3. 使用 **Alt+Z** 或弹窗主按钮切换整页翻译。主按钮会根据页面状态显示“翻译此网页”或“恢复原文”。

两种入口复用同一段的已完成结果和进行中的请求。启动整页翻译不会清除并重译已有段落；关闭一段不会取消其他段落，网页“恢复原文”会统一清除所有段落译文。失败段落的“重试”只重试该段。整页与段落共用双语 / 仅译文模式及 16 种样式。

旧版悬停弹窗设置会迁移为网页内显示，保留原来的启用状态、范围、网站例外和自定义按键；旧 Kuai 默认 Alt 按键在 1.5 中一次性更新为 Shift。划词翻译仍使用独立卡片。Escape 用于取消尚未触发的手势或关闭划词/输入卡片；关闭网页译文使用段落快捷键或“恢复原文”。

可选的“直接悬停”和“长按鼠标左键”仍在高级触发选择中，分别按等待时间自动触发；左键拖选不触发。它们只补充尚未翻译的段落，不会因反复进入而关闭已有译文。区域模式逐段翻译所在区域，仍遵循网页排除规则。

### 划词结果的关闭与固定

未固定的结果随原文选区取消而关闭；待完成请求也会取消，迟到结果不会把弹窗重新打开。在弹窗内复制、选择译文或操作按钮不会误关结果。

点击标题栏的 **图钉图标** 固定当前位置。固定后取消原文选区仍保留结果，下一次划词使用同一位置；拖动标题栏或聚焦标题栏后用方向键移动。窗口缩小时会把位置限制在可见范围内。取消固定且没有有效原文选区时关闭，关闭按钮始终可用。

固定位置只保留在当前页面的这次弹窗会话中，不保存跨网站坐标或翻译历史。路由、服务或功能设置失效时仍清理；固定不会让旧请求绕过这些检查。输入翻译与划词弹窗分别管理，输入操作不会挤掉固定的划词结果。

### 输入写回与恢复

输入翻译默认输出 **英文**，不随网页目标语言一起变化。聚焦合适的输入区后，小圆点显示在输入框内侧靠右下的位置，离最右边缘留出间距；小输入框会缩小入口，滚动和调整窗口大小时跟随位置。先点击圆点展开翻译图标，再点击图标；也可按 Alt+X 开始翻译，正常流程直接写回，不弹出结果卡。

选中部分文字就翻译该部分；没有选区时使用整个输入内容。默认圆点模式不显示文字反馈弹窗：点圆点展开图标，点图标翻译，完成后显示绿色勾，再点图标还原。翻译中点击图标取消，失败时点击图标重试。无法安全写回时保留原文，并允许复制译文。只有你主动关闭“自动写回”时才打开预览，之后再选择“应用”。开启“同时保留原文”时，按所选顺序用换行连接原文和译文。

**再次按 Alt+X 只恢复本扩展最近一次成功替换**，也可使用小圆点旁的“恢复原输入”。它不是多步历史记录；用户编辑、焦点移走、组合输入、选区或编辑器状态变化后，不会用旧内容覆盖当前输入，此时 Alt+X 重新翻译当前内容。Ctrl+Shift+Z 等编辑器快捷键不被占用。

在网页或输入框上右键选择“本站禁用输入翻译”，可只为当前域名关闭输入翻译，再次点击即恢复；勾选状态跟随当前标签页。如果是设置页里更宽的规则（如 `*.example.com`）禁用了本站，右键无法取消，会打开输入翻译设置。

密码、只读/禁用输入，以及明确标记为验证码或支付卡的字段不处理。简单富文本只在能够保留现有节点结构时写回；**跨越复杂富文本结构的选区保留复制入口，主动选择预览模式时也可查看预览**。编辑器拒绝写入或原输入已变化时，也保留可复制结果，不保证所有网页编辑器都支持自动替换。

### 网站、语言与排除规则

自动翻译默认关闭。开启后，“自动翻译的网站”和“自动翻译的原文语言”两项都留空表示允许符合条件的网页；填写后，**网站或原文语言命中任意一项**即可自动开始。已识别为目标语言的页面不自动翻译。手动停止或恢复后，同一页面路由不会立即自动重启。

“不翻译的网站”和“不翻译的原文语言”优先于允许条件，并限制**手动网页翻译与悬停翻译**。语言按网页声明或浏览器本地语言检测判断；未知语言不会被当成允许列表中的某项，也不能保证由语言禁用列表排除。划词、输入各有独立的网站禁用列表；悬停还有叠加在网页规则上的禁用列表。若要在某站停用全部相关入口，请分别配置这些分区。

所有列表每行一项。网站和语言列表各最多 100 项，CSS 选择器最多 50 项，每行最多 2000 字符。

| 规则示例 | 含义 |
| --- | --- |
| `example.com` 或 `*.example.com` | 匹配该域名及其子域名的任意路径，不会匹配 `notexample.com` |
| `https://example.com/news/*` | 仅 HTTPS，`*` 不跨越路径中的 `/` |
| `https://example.com/news/**` | 仅 HTTPS，`**` 可以跨多层路径 |
| `en`、`ja`、`zh-Hans` | 原文语言代码，每行一个；如 `en` 也匹配 `en-US` |
| `.advertisement`、`[data-private]` | CSS 排除选择器，每行一个；同时用于网页与悬停范围过滤 |

网站规则支持可选的 HTTP/HTTPS 协议和端口；不写协议时匹配两者。带路径的规则按完整路径、查询和片段匹配，不是正则表达式。CSS 排除命中段落内的子区域时，会保守跳过整个包含段落，避免把被排除文字发送出去。关闭“整页可读区域”会额外跳过页脚，不代表智能识别文章主体；编辑框、代码与扩展控件始终排除。

网页翻译启动后只翻译当前可见段落，滚动或追加可见内容时补译；离屏且尚未发送的任务会跳过，已完成的段落不会重复请求。不显示右下角进度工具条。动态翻译默认关闭；开启后还会自动更新已经变化的正文。网页“显示浏览器右键翻译菜单”统一控制全部 Kuai 右键入口；关闭划词或输入功能也会隐藏对应菜单项。

各分区可以单独恢复交互默认值，不会删除服务实例或重置其他分区的样式与字幕设置。开启自动网页翻译、动态翻译、自动划词或直接悬停，会按对应规则发送文本，无需每次点击确认；具体时机见[隐私说明](PRIVACY.md)。

## 网页显示与译文样式

扩展弹窗中的“网页设置”和“译文样式”入口会打开对应设置区；Alt+Z 或扩展弹窗仍可恢复网页原文。

- **原文 + 译文**：保留原段落，在其下方显示译文。
- **仅译文**：该段得到有效译文后才隐藏原文；等待、失败或取消时保留原文和提示。还原时复用原来的节点，保留事件处理器及网页后来做的修改。如果网站移除了扩展译文节点，会恢复对应原文，避免留下空白段落。
- **16 种预设**：左侧边线、跟随原文、细虚线下划线、虚线下划线、点状下划线、背景色、透明效果、橙色下划线、实线下划线、波浪下划线、马克笔、高亮、模糊遮盖、斜体、加粗、虚线边框。
- 可以调整字号比例、字重、字体名称、文字/边线/背景颜色、文字不透明度、斜体和行高。模糊遮盖可通过悬停或键盘聚焦临时揭示。

预览完全在本地使用示例文字。设置保存后，已有译文直接更新样式，**不会因为只改颜色、字号或显示模式而重新请求翻译**。“恢复网页样式默认值”只重置样式，保留服务、语言与显示模式。

### 译文中的链接

双语和仅译文模式都会为对应的译文保留原文链接，包括相对地址、页面锚点及普通 HTTP(S)、邮件和电话链接。相同的链接文字仍分别对应各自的地址；原有网页节点及其处理器保留，恢复原文时不会重建整段网页。

链接地址和属性在本地维护，不作为附加数据发送给翻译服务。仅地址、打开方式或网页基础地址改变时，已有译文链接会更新，无需重译；链接节点或文本结构改变时旧对应关系失效，开启动态翻译可按新结构处理。脚本地址不生成可执行链接，任意站点脚本按钮也不复制为链接。

为兼容目前的纯文本翻译服务，带链接的段落按原文文本与链接边界分段翻译，再按原节点对应关系组合。这能保留确定的链接归属，但链接附近的翻译可能减少上下文；不含链接的段落仍整段处理。

## 选择翻译服务

### 免 Key 服务

设置中预置以下四项，首次启动默认选择微软翻译：

| 服务 | 需要填写 API Key | 说明 |
| --- | --- | --- |
| 微软翻译 | 否 | 使用微软网页翻译接口 |
| 谷歌翻译 | 否 | 使用谷歌网页翻译接口 |
| 腾讯 Transmart | 否 | 使用 Transmart 网页翻译接口 |
| Yandex | 否 | 使用 Yandex 网页翻译接口 |

这些接口按 **best effort** 方式提供：实际可用性受服务方调整、地区网络、访问频率和限流影响，没有永久可用或不限量的承诺。它们是第三方网页接口，与需要自行申请密钥的正式云 API 是不同配置。某项失败时，可以在设置中切换其他服务，或配置自己的 API 后重试。

### 自配 API

打开“设置” → “翻译服务”，选择类型并点击“添加实例”。每个实例有独立名称、地址和配置，可以为同一种服务创建多个实例。

| 类型 | 主要配置 |
| --- | --- |
| OpenAI 兼容 API | API Key、获取并选择模型（也可手填）；可填写兼容服务的 API 地址 |
| Google Gemini | API Key、获取并选择模型（也可手填）；可使用默认或自定义地址 |
| Anthropic Claude | API Key、获取并选择模型（也可手填）；可使用默认或自定义地址 |
| Azure Translator | API Key；按所用服务填写地址和 Azure 区域 |
| DeepL API | API Key；按账户选择合适的 DeepL API 地址 |
| DeepLX / 自建接口 | 必须填写自己的服务地址；Key 按自建服务需要填写 |
| Ollama | 本地或自建 Ollama 地址，获取并选择已安装模型（也可手填）；Key 可留空 |

除 DeepLX 外，地址留空使用该类型的默认地址；Ollama 默认地址为 `http://localhost:11434`。OpenAI 兼容、Gemini、Anthropic 和 Ollama 可点击“获取模型”读取服务端列表，选择后自动保存；也可直接输入模型名，不依赖预置模型目录。**温度可以留空**，留空时不发送这个参数，由服务决定默认值。

点击“测试连接”会向该实例发起一小段实际翻译请求。确认可用后，在网页、划词或输入各自的设置区选择它。YouTube 的字幕服务和字幕目标语言都可独立设置，也可以分别跟随网页选择。停用实例不会删除其配置。

设置自动保存。若另一窗口同时修改了同一配置，页面会保留当前草稿并显示冲突；先复制需要保留的内容，再点击“重新读取（放弃未保存修改）”。连接测试成功只表示该次请求成功，不代表所有模型、语言和未来请求均可用。

## YouTube 使用方式

1. 打开 YouTube 视频。检测到播放器后，在原生右侧控制组的左边提供 **“译”开关、`⚙` 字幕设置和 `☷` 列表入口**；设置与列表不再等待字幕轨读取或翻译成功后才出现。YouTube 原有控件保持顺序，全屏按钮仍在最右侧。扩展弹窗也提供“字幕设置”和“展开侧边字幕列表”。
2. 翻译视频时开启播放器 **CC**，并启用字幕翻译。没有字幕、字幕关闭或读取失败时，列表会显示状态或操作提示，仍可打开设置调整服务。
3. 在 `⚙` 面板选择原字幕轨、字幕翻译服务和目标语言，以及视频浮层的双语 / 仅译文、显示顺序和学习遮罩。字幕下方不再常驻语言选择条。点击“字体、颜色与完整字幕设置”可调整高级样式。
4. 展开侧栏查看字幕，点击时间戳跳转；手动滚动时显示“自由阅读中”，按“回到当前字幕”恢复跟随；列表不会强行拉回你的阅读位置。播放器中的上一句／下一句按钮，以及 **Ctrl+Alt+← / Ctrl+Alt+→**，可在可用时间轴中跳到相邻字幕，保持原来的播放或暂停状态。没有可定位时间轴或已经到达边界时，导航按钮会禁用；输入文字时不接管快捷键。
5. 在字幕层或侧栏中选中文字，当前字幕固定，正在播放的视频暂停，后续字幕翻译调度暂停。取消选中时，只有本扩展因为这次选择暂停的视频才会尝试恢复；你原先的暂停、手动控制、跳转或视频切换不会被旧选择擅自撤销。

视频的“译”开关、原字幕轨偏好、列表展开状态，以及服务、目标语言、显示模式、顺序、遮罩和位置会保存，刷新后重新读取。原字幕轨保存语言、人工/自动种类及名称；新视频没有该轨道时暂用可用轨道，保留偏好供之后的视频匹配。“自动（跟随当前字幕）”清除固定轨道偏好。播放进度、选区、列表滚动位置和设置面板临时展开状态不保存。保存失败会提示，并恢复已保存的选项。

默认字幕外观参考原插件：**原文和译文均为 24 px 白字、常规字重、无描边，文字逐行铺 50% 黑色背景**。外层不再显示大块圆角背景；可在“背景形式”中改回“整块背景”。这是一组基础样式，不承诺不同播放器尺寸下与原插件逐像素一致。

字幕样式支持**原文和译文各自的字号、颜色、字重及描边/阴影**，以及字体、背景颜色、背景透明度、六个位置、边缘距离和最大宽度。这些外观、显示模式和顺序设置只用于视频浮层。右侧列表采用独立的阅读字号和明暗主题配色，固定原文在上、译文在下；学习遮罩同时用于两处，悬停或聚焦即可揭示。仅修改样式不会再次请求翻译。

字幕层和侧栏按可用宽度重新排版，字幕源自带的换行不再强制显示为断行；宽度不足时仍会自动换行，最大宽度与位置设置继续生效。这也会重新排版作者手工安排的断行，目前没有单独保留这些断行的选项。字幕文本数据不会为此被改写，但浏览器复制选中文字时的换行格式需以实际结果为准。

字幕服务或字幕目标语言更改后，会按新的翻译设置处理字幕。字幕目标语言选为固定语言时，网页目标语言的变化不会连带改变它。鼠标移动到字幕的空白背景会显示小手，拖动可调整垂直位置并自动保存；文字区域用于选词，不会开始拖动。完整设置仍可用数字修改位置和边缘距离。

功能依赖视频实际提供的字幕及 YouTube 当前页面结构。没有字幕时不会生成语音识别结果。若只能取得播放器当前显示的字幕，侧栏会提示其范围有限，不能保证获得整个视频的完整列表。读取或翻译失败时，检查 CC 和字幕语言，再使用重试。

### 自动字幕断句

已识别为自动生成的 JSON3 字幕会先在本地整理，再交给字幕层、列表和跳转时间轴共同使用。现在按 **120 字符的长度目标**预估段数并均衡拆分，优先逗号等从句标点，其次原字幕片段边界，再考虑普通词间空格；以 12 字符作为避免短碎尾句的偏好。继续结合约 8 秒的时长目标、约 0.8 秒的停顿及可用词级时间，不在完整单词或数字内部强行切断。

例如用户截图的长句会优先在 `After reading about this online and troubleshooting it a few times,` 后断开，后面的 `I realized…` 留到下一条，而不是等整句结束。该例已加入固定文本测试，测试时间是合成夹具，不代表原视频的音频测量。对有时间或重叠窗口依据的重复片段继续保守去重。

这个处理不调用额外的模型，也不会替原文补造标点。人工字幕保留原有分段；缺少精确时间的自动字幕只能使用较粗的时间边界，不能承诺达到人工校订的语义断句效果。其他字幕格式和原生回退仍按其可用数据处理。

## 文本与文件

点击扩展弹窗中的文本工具入口，或设置页中的“文本 / 文件翻译”，即可打开独立页面。

- 可以直接输入或粘贴原文，也可以选择不超过 **2 MB** 的 `.txt`、`.md`、`.srt` 或 `.vtt` 文件。
- 选择文件只在本地读取；点击“开始翻译”后，待翻译文本才发送给当前选择的翻译服务。
- 原文保留在左侧，译文显示在右侧；支持取消、复制和下载。只有存在当前译文时才能复制或下载，修改原文或更换文件会清除旧结果及完成提示。
- 长段落分片并分批翻译，不会为了适应单次请求长度而静默截断原文。
- SRT/VTT 保留时间信息；Markdown 保留围栏代码块、前置元数据和基本段落标记。复杂行内 Markdown、HTML 或富文本排版不保证无损，应检查导出结果。

这是文本翻译工具，不是 PDF、图片或 Office 版式转换器。

## 迁移与隐私

1.5 一次性更新可识别的 Kuai 旧默认值：1.4 的默认输入简体中文改为英文、保留入口选择；更早的“跟随网页 + 不显示入口”组合更新为“英文 + 小圆点”；旧默认段落 Alt 改为 Shift，保持原有启用状态。其他已选语言和非默认快捷键保留。旧版本未记录同值选项是否由用户主动选择，因此仍使用这些旧默认值的配置会一起升级；升级后主动改回中文或 Alt 会被记住，不再反复覆盖。

字幕只有整组视觉参数仍与旧默认一致时才迁移到新的逐行背景，位置和宽度继续保留。已改过字体、颜色等视觉参数的配置保留原样及整块背景，可点击“恢复字幕样式默认值”采用新样式。迁移不改服务实例或 API Key，三个分区仍可分别恢复默认。

Kuai translate 使用独立扩展 ID 和独立存储，**不会自动读取旧产品扩展中的设置**。请先导出可读取的 JSON 配置，再在 Kuai translate 设置页导入。当前版本继续迁移可识别的免费服务、用户直连 API、网页当前主题及其自定义值、字幕样式和独立目标语言，并补充网页语言/网址规则、划词与输入的独立服务和语言、公开触发字段、悬停按键/范围以及输入快捷键等。旧配置中明确启用的自动翻译规则可能开启自动翻译，导入后请先核对开关。

未选中的旧主题自定义值不转换为新配置；旧字号档位转换为像素，字幕背景透明度转换为百分比。多模型列表、自动评分选优、手机手势和上下文摘要字段不会转换成可用功能。

迁移读取支持的数据字段，不执行旧脚本或任意 CSS。非法或未支持的值可能回退默认值、限制到允许范围或跳过；平台账号、会员服务、登录凭据和共享付费服务不迁移。同一目录中的 Kuai translate 1.0 / 1.1 / 1.2.x / 1.3 / 1.4 更新保留原有配置，并为缺失字段补本项目默认值；1.0 的字幕“显示原文”兼容映射到新的显示模式。导入后请检查服务、模型、语言、触发条件和样式。

API Key 保存在扩展的本地存储中，翻译时由后台直接请求所选服务。没有 Kuai translate 账户或中转服务器。默认备份不包含 API Key；只有明确勾选包含密钥时才写入备份。不要将包含个人配置、密钥或私有文本的备份提交到 GitHub。

权限、数据发送与本地存储细节见 [PRIVACY.md](PRIVACY.md)；漏洞报告方式见 [SECURITY.md](SECURITY.md)。

## 开发与打包

| 命令 | 作用 |
| --- | --- |
| `pnpm test` | 使用 Node 内置测试运行器执行自动化测试 |
| `pnpm build` | 将 `src/` 和 `public/` 构建为可加载的 `dist/` |
| `pnpm check` | 检查现有 `dist/` 的清单资源、模块引用和 JavaScript 语法；需先构建 |
| `pnpm package` | 重新构建并检查，生成安装 ZIP、源码 ZIP 和 SHA-256 校验清单 |

1.0.0 的打包输出位于 `release/`：

```text
kuai-translate-1.0.0.zip
kuai-translate-1.0.0-source.zip
SHA256SUMS
```

源码 ZIP 只包括明确允许的项目源码、静态资源、测试和文档；安装 ZIP 只包括 `dist/` 的内容，其中 `LICENSE.txt` 保留项目的 MIT 许可文本。`dist/`、`release/`、Git 内部数据和个人环境文件不会作为源码提交。生成的 ZIP 使用固定条目顺序和元数据，便于在相同源文件和运行环境下复现。

GitHub Actions 在 push、pull request 或手动触发时执行测试与打包，并保存构建产物。**工作流不会创建 GitHub Release，也不会自动发布到扩展商店。** 架构、测试方法与发布前检查见 [开发说明](docs/development.md)。

先在自己的 GitHub 账户下创建一个空仓库。下面的地址是占位符，需要替换成你实际创建的仓库地址。

## 验证状态与问题反馈

自动化测试使用可控的 DOM、浏览器消息与 HTTP 响应边界，覆盖服务适配、配置保存、正文输出、段落/整页共用结果与独立取消、字幕文本和样式、选择/侧栏状态以及打包行为。**当前交付未完成真实浏览器像素排版、YouTube 和在线翻译 API 的端到端验证。** 自动测试通过不等于已验证所有网站布局、实际字幕行数、地区网络或第三方接口可用性。
