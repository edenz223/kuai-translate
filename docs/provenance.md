# 源码来源与授权范围

更新日期：2026-11-03

## 这个仓库是什么

**Kuai translate 是独立编写的原生 JavaScript / Manifest V3 浏览器扩展。** 本仓库包含可维护的功能源码、测试、原生界面与构建脚本，按 [MIT License](../LICENSE) 发布这些独立代码和文档。

项目源于用户希望获得无需平台登录、支持自配 API 和免费服务，并具有 YouTube 字幕列表与选中文字暂停交互的扩展。开发过程中曾检查用户提供的 SelectTranslate 编译包的现有行为和配置格式，用于识别问题、梳理需求和编写有限的配置迁移逻辑。发布工程随后选择了独立实现，而不是把原编译包改名后当作完整源码发布。

本次开发中先行独立编写的字幕选中与列表交互组件，经整理后被复用于新工程。它们与新写的后台、服务适配器、页面翻译、设置界面及测试一起构成本仓库；它们不是从原包的压缩业务代码中提取出来的源码。

1.2 的细分交互以旧配置字段、选项标签及可辨认的触发行为作为需求参考，再独立实现规范化、快捷键与按住键处理、网址规则、输入快照/单步恢复、调度和设置界面。没有复用原包的编译业务代码、品牌资源或共享 Key。新安装默认值延续 Kuai translate 的选择；只有导入时明确存在且受支持的旧字段才参与迁移。

1.4 检查了用户提供的旧包中可辨认的字幕解析、重叠窗口整理和句子分组逻辑，作为自动字幕断句的行为参考。新的 `asr-segmentation.js` 为独立编写：仅对明确的自动生成 JSON3 轨道处理，结合词级时间、停顿、标点及长度边界，不引入旧包的编译代码或额外模型服务。旧包里的规则与本项目的保守去重、轨道身份校验并不完全相同；没有完成旧插件与本项目的真实视频逐句效果对照，不声称功能或断句效果完全一致。

1.5 再次检查旧包可辨认的长句切分与字幕基础样式：120 字符/12 字符的长度参数、均衡段长、标点/原片段/空格的候选优先级，以及白色常规字重、无描边、逐行半透明黑底。依据这些行为独立调整本项目的时间保留与分组实现，并用用户截图文本加入回归；没有复制旧业务函数。默认样式没有采用旧包的视频宽度缩放算法，不声称在所有播放器尺寸下逐像素相同。译文链接采用本项目自行实现的文本片段与本地节点映射，不复用旧包的 HTML 处理代码。

配置兼容范围不包含旧多模型评分选优、手机手势或上下文摘要能力。复杂富文本选区只提供安全预览/复制，不据此声称完整编辑器兼容；详情以当前源码、功能说明和验证记录为准。

功能支持范围以 [README 中的功能矩阵](../README.md) 为准，英文说明见 [README.en.md](README.en.md)。本项目不声称恢复或兼容旧产品的全部功能。

## 没有随本工程分发的旧包内容

源码包和可加载的扩展包不包含旧 SelectTranslate 的编译业务包、商业界面资源或其打包的第三方运行库，也不继承旧扩展的签名 `key`、商店扩展 ID、更新地址或品牌图标作为 Kuai translate 的身份。

本项目没有内置旧包使用的共享 Google API Key。当前 Google 免费适配器调用无需填写个人 Key 的网页翻译接口；需要 Key 的自配服务只使用用户保存的凭据。测试中的 Key 字符串为假数据，不提供可用的公共密钥。

旧产品名称、域名或配置字段可能出现在迁移代码和说明中，用于辨认旧配置或排除旧平台代理条目。这不表示 Kuai translate 使用旧平台服务，也不表示旧产品为本项目提供支持。
