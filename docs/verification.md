## 未执行的实机验证

**本次没有完成真实 Chromium、真实 YouTube 或在线翻译 API 的端到端验证。** 当前环境没有可用浏览器二进制；受控 DOM/媒体测试不等于原生鼠标命中、文字选择或像素排版检查，也不能证明所有网站、地区网络、配额或第三方免费接口始终可用。

字幕自动换行检查确认数据与 CSS 契约，没有测量真实播放器实际行数。自动字幕断句以固定文本/时间夹具验证，不是对原视频音频逐句校对，也不是与旧插件的实时效果比较。缺少词级时间时会使用估算，不可再分的长单词可能超过分组目标。作者安排的硬换行会视觉重排，浏览器复制文字时的具体换行格式尚未核实。列表与 KISS 的对照基于公开项目说明和交互方向，不是逐像素视觉比较。

截图文字已加入固定回归，其时间为合成夹具。不可再分的数字也可能超过分组目标；空格数字分组与连续报数存在文字歧义，按保留内容和避免过长片段处理。默认字幕没有移植旧插件按视频宽度缩放字号的算法，不将基础外观等同于所有播放器尺寸下的像素复刻。

视频选项使用实际控制器与后台重建检查，仍不等于在浏览器按刷新键。链接检查验证原生节点、对应关系及默认导航条件，未实测新标签页、上下文菜单或站点脚本导航。带链接段落按文本/链接片段分别翻译，可能减少跨片段上下文；不含链接段落仍整段处理，任意非原生脚本控件不复制其行为。

建议在 Chrome/Edge 中优先检查划词取消与固定、影子 DOM 内复制和键盘操作、输入圆点与屏幕边缘反馈、普通/影院/全屏下的原生按钮位置、自动字幕对音频的断句和跳转、长列表选词与返回当前句，以及快捷键和缩放下的设置布局。完整场景见 [开发说明](development.md)。

GitHub Actions 已随源码提供。本次未创建或推送远程仓库，未运行远程 CI、创建 GitHub Release 或向商店发布。
