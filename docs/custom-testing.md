# 定制版测试说明（2026-11-03）

源码位置：/home/edenz/codes/kuai-translate。

1. Chrome/Edge 扩展管理页打开开发者模式，选择“加载已解压的扩展程序”，选择交付目录中的 extension 文件夹。
2. 新安装时段落快捷翻译默认开启，划词翻译默认关闭。鼠标指向网页段落，按下并松开 Shift 翻译，再按一次关闭。
3. 输入框内出现简洁灰色圆点。输入和悬停不发送翻译请求；第一次点击圆点只展开翻译图标；点击图标才按输入翻译的目标语言翻译，默认英文，并安全写回。翻译完成后图标保持展开并显示绿色勾，再点击同一图标还原原输入，勾随之消失；不显示文字反馈弹窗。再次点击圆点或点击外部可收起图标。
4. 在设置中手动开启划词翻译后，选中文字查看结果；标题栏图钉图标可以固定/取消固定，固定后可拖动标题栏。
5. 已保存的开关、服务与语言配置保留。若加载原扩展目录，先检查设置中的两个开关；新默认值不会覆盖明确保存过的选择。

验证：757 项自动测试通过；构建与本地资源引用检查通过。尚未进行真实浏览器、在线服务的端到端测试。

Alt+X：同一输入框内第一次翻译，第二次还原。文字未改时移动光标、改变选区或输入框自身样式不再使还原失效；实际输入、失去焦点、富文本结构变化等仍会清除还原资格。

视频字幕：开头暂时没有可读字幕时不显示提示文字；后续捕获到字幕仍正常显示，已有原生字幕回退继续保留。

YouTube 视频标题：双语翻译使用原文在上、译文在下的完整宽度布局，避免标题 flex 横排挤成左右两列；恢复原文时清理专用布局样式。

网页翻译：右下角不再显示进度工具条。启动后只翻译当前可见段落，随页面或内部容器滚动补译新出现的内容；已完成内容不重复请求，未发送的离屏任务会跳过。Alt+Z 或扩展弹窗可恢复原文，恢复后滚动不会继续翻译。

2026-11-04 界面调整：网页请求期间仅在原文末尾显示独立定位的小转圈，不显示“翻译中”占位，不占段落行高或 flex/grid 间距；完成后移除。译文链接的下划线跟随原链接。YouTube 字幕列表按钮始终透明，关闭暗、开启白，不再出现方框背景。
