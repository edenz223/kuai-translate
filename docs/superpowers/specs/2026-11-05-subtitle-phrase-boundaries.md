# ASR phrase boundary improvement

Current design is the SelectTranslate port described in the final section below; it supersedes the initial duration and 160-character rules.

User approved phase one: semantic boundary priority, soft length limits, phrase protection.
The initial phase changes only JSON3 ASR grouping. Authored tracks, source timing anchors, source text,
speaker/music boundaries, translation units and overlay wrapping remain unchanged.

Keep 120 characters / 8 seconds as reading targets. Permit up to 160 characters /
10 seconds to retain complete short phrases. Never split indivisible source words
or numbers merely to meet a limit. Prefer clause punctuation and conjunctions;
source event boundaries alone are not semantic evidence. English protection is
a conservative local heuristic, not a grammar parser. Use Intl.Segmenter word
boundaries for CJK when available. Preserve numeric punctuation and spaced groups.
Without a semantic cut, keep a phrase inside the upper bounds intact; above them,
use a bounded lexical fallback and retain monotonic timestamps and exact text.

No remote language model, extra permission, user setting, or runtime dependency.
Validate slow short speech, long speech, conjunctions, Chinese words, number groups,
speaker changes, full suite and Chromium smoke. Export ZIPs then copy to Windows
release/kuai-translate-1.0.0 and extract.

## User-directed SelectTranslate algorithm port (current)

The user explicitly requested following the local SelectTranslate implementation.
Reference: G:/code_project/SelectTranslate/content.js, GXe at 186789–186903,
KXe/WXe normalization and constants at 186700–186940. The readable implementation
ports its behavior, not the unrelated extension runtime.

- Buffer unfinished source tails. Use Intl.Segmenter granularity=sentence.
- Process at original source event boundaries; compact completed sentences within
  one source window use the reference 12-character minimum.
- Split only long sentences at about 120 characters. Score candidate distance
  from a balanced target plus 0 for clause punctuation, 25 for original source
  boundaries and 50 for spaces. Flush unresolved buffers beyond 240 characters.
- Remove duration-based 8/10-second splits and the prior 160-character rule.
- Retain explicit source timing anchors; interpolate only within original spans.
- Keep numeric safety, CJK lexical boundaries, Korean spacing, voice/speaker and
  actual pause/overlap boundaries. Do not merge unrelated spoken counts.
- Collapse overlapping strictly growing ASR windows of the same identity while
  retaining independent/repeated speech. Skip line-overlap removal after replacing
  an entire growing window so earlier lines cannot be discarded twice.

Nine golden fixtures were generated by executing the extracted pure GXe function
from the local reference with its original constants in a Node VM. They cover slow
sentences, multiple sentences per source cue, short sentences, the screenshot,
long comma/space fallback and numeric punctuation. Golden text outputs match;
timing preserves Kuai's source anchors rather than adopting the reference's global
character-proportional estimate.
