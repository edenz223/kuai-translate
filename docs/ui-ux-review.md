# UI/UX 整理

## 1.5.0：记住操作，缩短字幕，保留链接

| 场景 | 当前行为 | 设计理由 |
| --- | --- | --- |
| 输入与段落默认动作 | 输入输出英文；指向段落后按一次 Shift 开关译文 | 按用户纠正后的习惯设置，整页 Alt+Z、输入 Alt+X 保持可区分 |
| 刷新视频 | 恢复翻译开关、字幕轨偏好、列表展开与已选显示参数 | 不必每次重复选择；没有匹配轨道时临时回退，不丢掉偏好 |
| 自动字幕长句 | 120 字符目标下均衡拆分，优先从句和原片段边界 | 让当前画面承载可读片段，避免一个完整长句占据多行 |
| 视频字幕外观 | 两种语言同为白色常规字重，逐行半透明黑底；整块背景可选 | 减少大块背景和过重译文，让原文与译文更接近用户参考样式 |
| 翻译后的页面链接 | 译文中保留各自对应的可点击链接 | 用户可以继续从译文阅读和导航，不必切回原文找链接 |
| 升级已有设置 | 识别旧默认值一次性更新，自定义外观保留，分区可重置 | 新默认可见，同时避免每次加载覆盖后续选择 |

链接映射以原节点身份为依据，链接边界拆分可能减少翻译上下文。视频字幕外观只落实基础字号/颜色/字重/背景，实际行数仍依赖播放器尺寸和字体。验证范围见 [验证记录](verification.md)。以下 1.4 和 1.3 小节保留历史设计背景；实际操作说明按当前版本更新。

## 1.4.0：减少必须关闭的界面，保留明确的固定入口

本轮直接落实四项使用反馈。默认操作路径保持简短，固定、预览和恢复仍有明确入口。自动化检查与未完成的实机项目见 [验证记录](verification.md)。

| 场景 | 1.4.0 行为 | 设计理由 |
| --- | --- | --- |
| 划词完成后继续阅读 | 取消原文选择即关闭未固定卡片；等待中的请求也取消 | 卡片生命周期对应当前阅读选择，无需每次寻找关闭按钮 |
| 需要持续查词或比较 | 点击图钉图标固定卡片，可拖标题栏或用方向键移动；新选择复用坐标 | 用户明确选择保留，避免新结果在页面上反复跳位 |
| 复制卡片文字 | 文字节点保持稳定，卡片内选择和控件操作不会被当作离开原文直接关闭 | 自动关闭不能妨碍使用译文本身 |
| 输入内容翻译 | 默认简体中文；输入框内侧显示小圆点，点击或 Alt+X 直接写回 | 输出目标明确，入口离开最右边缘，减少覆盖站点自己的按钮 |
| 输入翻译状态与异常 | 轻量反馈提供取消、重试、恢复和安全复制；显式选择预览时才出现结果卡片 | 成功时不打断输入，失败或不能安全写回时仍可处理结果 |
| 视频按钮位置 | 扩展控件位于原生右侧按钮组左边，原生全屏保留最右 | 保留用户熟悉的全屏位置，控制栏重建后仍检查真实位置 |
| 自动字幕阅读 | 在有明确自动轨道信息时，本地按时间、标点、停顿和长度分组 | 减少短碎片造成的阅读中断，保留词序和正常重复讲话；没有音频级语义断句保证 |

固定坐标只属于当前页面卡片，不是跨网页的系统置顶窗口。输入和划词互相独立：输入翻译不会挤掉固定的划词结果。字幕断句同时服务视频和侧栏，不另建一套容易错位的导航时间轴。

## 1.3.0：网页与段落、视频与列表

本轮以“同一内容只维护一套译文，操作结果直接对应用户意图”为原则，检查网页、段落、划词、输入、视频字幕、字幕列表、弹窗、设置和文本工具。下面列出已经落实的改动，以及保留原行为的原因。测试范围见 [验证记录](verification.md)。

## 已落实的交互改动

| 入口 | 原先的问题 | 1.3.0 行为 | 对用户的帮助 |
| --- | --- | --- | --- |
| 段落与整页 | 两套结果和生命周期；按住快捷键、松开取消等规则不一致 | 共用段落记录、请求、渲染、样式和恢复；指向段落后按一次快捷键开启，再按一次关闭 | 只记住一个切换动作，松键后不必守着请求 |
| 段落请求 | 段落与全文重叠时可能重复；取消批次等待可能阻塞后续工作 | 整页复用成功与待完成结果；关闭一段不会取消其他段仍需要的请求；没有段落需要某请求时立即继续处理队列 | 不重复花费请求，关闭一个段落不影响其他段 |
| 网页恢复与重试 | 多种清理入口不容易判断范围 | 全局恢复统一清除；再次按段落快捷键只关闭该段；错误重试只处理该段 | 操作范围与当前位置一致 |
| 视频字幕 | 字幕下方常驻语言/拖动控件，占用观看区域 | 仅保留字幕和必要状态；空白背景显示小手并可垂直拖动，文字保持可选择 | 画面更简洁，移动和选词有各自明确区域 |
| 字幕设置 | 常用观看内容和低频配置混在一起 | 字幕轨、服务、目标语言等放入既有设置；无字幕或读取失败仍可打开设置 | 平时少干扰，需要配置时仍找得到 |
| 右侧字幕列表 | 继承视频字号、颜色、背景和显示模式，影响阅读 | 独立紧凑双语排版，原文在上、译文在下；视频仅译文也保留列表原文 | 视频用于观看，列表用于对照和查句 |
| 列表跟随 | 手动阅读和自动滚动的状态不够明确 | 显示“正在跟随 / 自由阅读中”；手动阅读后出现“回到当前字幕” | 可以安心查阅前文，再主动返回播放位置 |
| 扩展弹窗 | 翻译和恢复分散，按钮可能与页面实际状态不一致 | 一个主按钮按当前页面状态显示翻译或恢复；执行前再次读取状态 | 入口与页面结果保持一致 |
| 弹窗配置与操作 | 保存尚未传播到页面就开始动作；失败数也可能混入成功提示 | 操作前页面读取当前设置，期间锁定相关选择；保存不等待无关标签页；成功与失败分别显示 | 使用刚选择的语言和开关，明确知道哪些段落失败 |
| 保存反馈 | 冲突、普通失败、成功恢复的提示可能混杂 | 明确区分保存中、未保存、冲突和恢复方法；成功保存后清除旧错误 | 不把未保存的值当作已生效 |
| 设置结构 | 悬停独立分区与网页设置重叠；等待时间对键盘模式没有意义 | 段落放入网页翻译；键盘模式隐藏等待时间；网站例外折叠，导航和保存状态保持可见 | 减少重复配置和与当前操作无关的控件 |
| 文本工具 | 编辑原文或读取新文件失败后仍可能复制、下载旧译文 | 失效时清除旧输出；无有效内容时禁用对应按钮；取消只在运行时出现 | 当前原文与可复制、下载的结果保持对应 |

## 实际操作

### 网页与段落

段落快捷翻译保留原有启用状态，新安装默认开启。可在弹窗直接开启，也可到“网页翻译 → 段落快捷翻译”设置按键。

1. 指向段落，按下并松开一次 Shift，开始翻译；请求继续到完成。
2. 再按一次 Shift，移除该段译文或取消尚未完成的段落；迟到结果不会重新出现。
3. Alt+Z 或弹窗主按钮根据整页当前状态切换翻译/恢复。页面已有段落结果时，“恢复原文”包含这些结果。

直接启动整页翻译的入口会复用已有段落结果和请求。双语/仅译文及样式统一由网页设置决定。划词使用独立结果卡片，输入使用独立写回、可选预览和单步恢复；这两类操作需要自己的结果处理，不强行并入页面段落。

保留旧的直接悬停、长按左键和自定义键设置。鼠标自动触发只补充尚未翻译的段落，不因重复进入而关闭译文。旧悬停弹窗偏好统一迁移为网页内显示，保留启用状态、范围及网站例外，旧默认 Alt 在 1.5 一次性改为 Shift；密钥和无关服务配置不随显示方式迁移。

### 视频与阅读列表

字幕文字区域使用文字选择光标，空白背景使用拖动光标。拖动完成保存垂直偏移；取消、切换字幕或播放器布局变化不会提交过时的位置。完整设置中的偏移输入仍提供键盘调整方法。

列表采用独立的阅读层级，保留时间戳跳转、当前句标记、虚拟列表和学习遮罩。选中字幕仍固定文字并暂停翻译调度；只恢复由扩展因该选区暂停的播放。“回到当前字幕”恢复列表跟随，不替用户开始播放。

本轮参考 [KISS Translator 官方项目说明](https://github.com/fishjar/kiss-translator/blob/dev/README.md) 中的 YouTube 双语字幕与完整对照列表方向。紧凑字号、固定阅读顺序和返回当前句是本项目结合现有行为作出的设计选择，没有复制其源代码、品牌或素材，也没有声称完成逐像素复刻。

## 保留的边界与后续实机检查

本轮没有新增运行时依赖，继续保留免 Key 服务、自配 API、配置备份和不含登录/推广的产品结构。公开设置分发不包含私有服务凭据。输入保护、页面排除规则、字幕暂停归属和辅助键盘入口继续参与回归。

已用实际源码配合受控 DOM、播放器、存储和消息边界检查交互状态及生命周期。当前环境没有可用浏览器二进制，未验证真实像素、原生拖动命中、浏览器 Alt 键与菜单冲突、真实 YouTube 布局或在线服务可用性。

发布前的实机检查应优先覆盖：普通/影院/全屏下的字幕换行与拖动；长列表手动阅读及返回当前句；小窗口和浏览器缩放下的设置导航与保存栏；输入法、键盘选择和系统占用快捷键。这里只列需要验证的既定交互，不把未经验证的视觉效果写成已通过。
